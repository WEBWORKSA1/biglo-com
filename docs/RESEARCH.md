# Competitive research: 28 sites reviewed (September 2026)

Sites reviewed: NerdWallet, Bankrate, The Zebra, Policygenius, LendingTree, Credible, SmartAsset, EnergySage, Rocket Money, Credit Karma, MoneySavingExpert, Clark.com, The Penny Hoarder, Kiplinger, Money Crashers, Slickdeals, DealNews, Brad's Deals, Hip2Save, The Krazy Coupon Lady, RetailMeNot, Rakuten, Honey, Coupons.com, Groupon, Ko-fi, Buy Me a Coffee and Gleam.

## Features adopted in Biglo
| Pattern | Seen on | Where it lives in Biglo |
|---|---|---|
| ZIP-first, one-field start | The Zebra, EnergySage, Bankrate | Homepage quick-quote |
| First-person, result-named CTAs ("Get my quotes", "Lower my bills") | The Zebra, Rocket Money, Credible | All CTAs |
| One question per screen, progress bar, 2-minute promise | SmartAsset, Credible, LendingTree | quotes.html funnel |
| Reassurance next to the button ("No spam calls", "never sold") | The Zebra, Credible | Funnel, hero |
| Capped matching ("up to 3") and "real humans, no bots" | Policygenius | Funnel, About |
| "How we make money" disclosure | Bankrate, NerdWallet | disclosure.html, footer |
| Deal badges: Staff Pick, Exclusive, Ends Today, community votes, COPY CODE | DealNews, Slickdeals, Brad's Deals | deals.html |
| Deal Alerts | Slickdeals, DealNews | deals.html |
| Calculator with the result feeding a quote CTA | NerdWallet, Bankrate, SmartAsset | tools.html |
| Guide anatomy: takeaways, TOC, in-content widget, FAQ schema | Penny Hoarder, NerdWallet | guide-*.html |
| Newsletter with a clear promise and schedule | Money Crashers, Kiplinger, DealNews | Band on every page, exit-intent popup |
| Preset donation amounts, one-time/monthly toggle, supporter message | Buy Me a Coffee, Ko-fi | support.html |
| Bonus entries, referral links, countdown | Gleam | contests.html |
| Referral program | Policygenius, Rakuten | ?ref= tracking in the funnel and contest |

## Deliberately NOT copied
- Inflated social-proof numbers ("74M quotes"). Biglo shows only true figures until real data exists.
- Fake testimonials and ratings. Add real Trustpilot or Google reviews once they are collected.
